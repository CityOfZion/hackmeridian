## Project layout

```
index.ts                    registerRootComponent → src/App
metro.config.js             Uniwind Metro wrapper (keep it outermost)
src/
  App.tsx                   imports global.css; Redux Provider → SafeAreaProvider → Navigation
  global.css                Tailwind v4 + Uniwind entry
  env.d.ts                  '*.css' module declaration (TS 6 checks side-effect imports)
  uniwind-types.d.ts        generated by Metro, committed
  navigation/index.tsx      all navigators + RootNavigator type augmentation
  screens/                  one component per screen, named export `XScreen`
  store/index.ts            configureStore + combineSlices, RootState / AppDispatch
  store/hooks.ts            typed hooks
  store/slices/             one createSlice per file, selectors defined in the slice
```

## Adding things

- **Screen**: create `src/screens/FooScreen.tsx`, register in the right navigator in `src/navigation/index.tsx`. If it takes params, type props with `StaticScreenProps<{ ... }>`.
- **Slice**: create `src/store/slices/fooSlice.ts`, add it to `combineSlices(...)` in `src/store/index.ts`. Export actions and `slice.selectors`.
- **Native dependency**: `npx expo install <pkg>`. Native modules outside Expo Go need a dev build.

## Before finishing a task

- `npx tsc --noEmit` passes. If `className` errors appear, run Metro once (`npx expo start`) to regenerate `src/uniwind-types.d.ts`.
- `npx expo-doctor` passes after any dependency change.
